# Dhandho Restaurant — v2 demo (compiled build)

The full restaurant app, now running as a **Dhandho OS v2 app**: every screen the
shop uses, plus a bridge that mirrors each bill onto the shared Dhandho spine
(one Invoice, one catalogue, ingredient stock, the events the assistant reacts to).

Compiled output only — no source. Runs entirely in your browser, offline, with the
data stored on your own device. Built by Buildanta.
